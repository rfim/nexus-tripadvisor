04 · The stream job · Python, with a Java twin

Event time, decided by the watermark

The watermark is the minimum over active partitions, less the out-of-orderness. A quiet partition stops holding it back; when every partition is quiet, processing time carries it.

wm = max(wm, minactive p max_event(p) − ooo) · fire ⟺ end ≤ wm · drop ⟺ end + lateness ≤ wm
src/nexus/stream.pyFlink semantics
    def _watermark(self, now: int) -> int:
        active = [self.s.part_max[p] for p, seen in self.s.part_seen.items() if now - seen < IDLE]
        if active:
            wm = min(active) - self.ooo
        elif self.s.part_max:           # every partition idle: let processing time carry the watermark (a heartbeat)
            wm = now - self.ooo - IDLE
        else:
            wm = NEG
        return max(self.s.wm, wm)

    def _emit(self, key, w: dict, now: int):
        value = {"n": w["n"], "sum": round(w["sum"], 4)}
        old = self.sink.get(key)
        self.sink[key] = {"value": value, "first_emit": old["first_emit"] if old else now, "last_emit": now,
                          "emits": (old["emits"] if old else 0) + 1}
        self.emits.append((now, key[0] + self.size))

    def _advance(self, now: int):
        wm = self._watermark(now)
        if wm <= self.s.wm and self.s.wm != NEG:
            return
        self.s.wm = wm
        if not self.windowed:
            return
        done = wm - wm % self.size
        if not self.progress or done > self.progress[-1][1]:

The rules

Fire when the watermark passes a window's end; re-fire on a late record within the hour; past it, the side output.

Dedupe on event_id, kept 24 hours. Dead letters for what can't be read, with the reason.

Offsets, windows, dedupe state and the ledger are checkpointed together; sinks are keyed, so a restore re-sends without changing anything.

In the run

A TaskManager lost at 09:17: restored from the 09:10 checkpoint, 55 windows re-sent, sink identical.

06 · Snowflake and BigQuery from one contract

Write it once. Mask it everywhere.

contracts/sources.yml names the personal fields. The DDL, MERGE, masking and erasure for both warehouses are generated from it and committed; CI fails if they drift.

warehouse/snowflake/reviews_current.sqlgenerated
MERGE INTO NEXUS.GOLD.REVIEWS_CURRENT t
USING NEXUS.STAGE.REVIEWS_CURRENT s
  ON t.review_id = s.review_id
WHEN MATCHED AND s.erased AND s.version > t.version THEN DELETE
WHEN MATCHED AND NOT s.erased AND s.version > t.version THEN UPDATE SET location_id = s.location_id, rating = s.rating, status = s.status, lang = s.lang, version = s.version, _loaded_at = CURRENT_TIMESTAMP()
WHEN NOT MATCHED AND NOT s.erased THEN INSERT (review_id, location_id, rating, status, lang, version, _loaded_at)
  VALUES (s.review_id, s.location_id, s.rating, s.status, s.lang, s.version, CURRENT_TIMESTAMP());

Same product, two dialects

Layout: CLUSTER BY (TO_DATE(window_start), partner) · PARTITION BY DATE(window_start) CLUSTER BY partner

Personal data: masking policy, SHA2 unless PII_READER · policy tag + data masking rule

Erasure list: FLATTEN(PARSE_JSON(:review_ids)) · UNNEST(@review_ids)

08 · Apache Flink 1.20 · DataStream API

The same job, on Flink

Parse with a dead-letter output, dedupe in keyed state, per-partition watermarks, event-time windows with allowed lateness, a side output for what's too late.

records → Parse ⟶ DLQ · keyBy(id) → Dedupe(TTL 24 h) · keyBy(group) → Tumbling(1 h) → allowedLateness(1 h) ⟶ late
flink/job/.../NexusJobs.javaFlink 1.20.1 · Java 17
    public static Outputs build(DataStream<KafkaRecord> records, Product p, boolean replayWatermarks) {
        SingleOutputStreamOperator<Event> parsed = records.process(new Parse(p.topic())).name("parse " + p.topic());
        SingleOutputStreamOperator<Event> unique = parsed.keyBy(e -> e.id).process(new Dedupe()).name("dedupe on id");
        final long ooo = p.outOfOrderness().toMillis();       // a long, not the record: the lambda is serialized
        DataStream<Event> timed = replayWatermarks
                ? unique.assignTimestampsAndWatermarks(WatermarkStrategy
                        .<Event>forGenerator(ctx -> new PartitionWatermarks(ooo))
                        .withTimestampAssigner((e, ts) -> e.eventTime)).name("watermarks")
                : unique;
        SingleOutputStreamOperator<WindowRow> windows = timed
                .keyBy(e -> e.group)
                .window(TumblingEventTimeWindows.of(p.window()))
                .allowedLateness(p.lateness())
                .sideOutputLateData(TOO_LATE)
                .aggregate(new Windows.CountSum(), new Windows.Emit())
                .name(p.name());
        return new Outputs(windows, parsed.getSideOutput(Parse.DEAD_LETTERS), unique.getSideOutput(Dedupe.DUPLICATES),
                windows.getSideOutput(TOO_LATE));
    }
}

One honest difference

08 · Apache Flink · production

On Kafka, with the incident's lessons built in

NexusKafka runs the same topology from KafkaSource to transactional Kafka sinks. Compiled in CI; there is no cluster behind a portfolio.

flink/job/.../NexusKafka.javaKafkaSource · KafkaSink
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.enableCheckpointing(Duration.ofMinutes(10).toMillis(), CheckpointingMode.EXACTLY_ONCE);
        env.getCheckpointConfig().setMinPauseBetweenCheckpoints(Duration.ofMinutes(1).toMillis());
        // 3 restarts in 10 minutes, then fail and page: a poison pill never crash-loops for 74 minutes again
        env.setRestartStrategy(RestartStrategies.failureRateRestart(3, Time.minutes(10), Time.seconds(30)));

        KafkaSource<KafkaRecord> source = KafkaSource.<KafkaRecord>builder()
                .setBootstrapServers(brokers)
                .setTopics(p.topic())
                .setGroupId("nexus-" + p.name())
                .setStartingOffsets(OffsetsInitializer.committedOffsets())
                .setDeserializer(KafkaRecordDeserializationSchema.of(new RecordSchema()))
                .build();
        // per-partition watermarks and idleness come from the source itself, one generator per split
        WatermarkStrategy<KafkaRecord> wm = WatermarkStrategy.<KafkaRecord>forBoundedOutOfOrderness(p.outOfOrderness())
                .withIdleness(Duration.ofMinutes(5))
                .withTimestampAssigner((r, kafkaTs) -> eventTime(r, kafkaTs));

        Outputs o = NexusJobs.build(env.fromSource(source, wm, "kafka " + p.topic()), p, false);
        o.windows().map(NexusKafka::row).sinkTo(sink(brokers, "gold." + p.name())).name("upsert gold." + p.name());
        o.deadLetters().map(NexusKafka::dead).sinkTo(sink(brokers, "dlq." + p.topic())).name("dlq." + p.topic());
        o.tooLate().map(e -> e.id + "," + e.eventTime).sinkTo(sink(brokers, "late." + p.topic())).name("late." + p.topic());

What the incident changed

Dead letters to dlq.partner_clicks, never a crash loop.

failureRateRestart(3, 10 min): three restarts, then fail and page. 74 restarts can't happen again.

Exactly-once checkpoints every 10 minutes and transactional sinks: a restore re-sends nothing twice.

Watermarks

Per split from the source: forBoundedOutOfOrderness(ooo).withIdleness(5 min), so a quiet partition can't hold the job back.

The page_views job, in plain JDK 17 with no framework. CI compiles it, runs it on the same week, and fails if a single window differs from the Python job.

java/src/nexus/WindowJob.javaJDK 17 · no dependencies
    void process(Rec r, long now) {
        count("read");
        Map<String, Object> v = Json.object(r.value());
        String id = (String) v.get("event_id");
        if (seen.containsKey(id)) {
            count("duplicates");
            return;
        }
        seen.put(id, now);
        long et = Instant.parse((String) v.get("event_time")).toEpochMilli();
        partMax.merge(r.partition(), et, Math::max);
        partSeen.put(r.partition(), now);
        long start = et - Math.floorMod(et, SIZE);
        Key key = new Key(start, (String) v.get("location_id"));
        if (start + SIZE + LATENESS <= wm) {
            count("late_dropped");
        } else {
            Window w = windows.computeIfAbsent(key, x -> new Window());
            w.n++;
            count("accepted");
            if (w.fired) {
                count("late_updates");
                emit(key, w);
            }
        }
        advance(now);
